# Sign Language Recognition

Real-time hand gesture recognition using Python, OpenCV and MediaPipe.

## Features
- Real-time webcam detection
- Hand landmark tracking
- Gesture recognition

## Supported Gestures
- FIST
- OPEN PALM
- ONE
- PEACE
- THREE
- FOUR
- THUMBS UP

## Run
python app.py

## Technologies Used
- Python
- OpenCV
- MediaPipe
